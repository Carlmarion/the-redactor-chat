# Architecture overview

Owned by the platform team from 2027.

The route-planning system has four parts: the planner web app, the routing engine, the tracking service and the new event bus.

The planner web app is where planners build daily routes. The routing engine computes routes overnight and on demand. The tracking service receives truck positions every 10 seconds and shows them on the planners' map. The event bus connects them, so a delay reported by a truck reaches the planner within a few seconds.

All four run in our own Kubernetes cluster in an Amsterdam data centre. The routes database is PostgreSQL with a hot standby.
