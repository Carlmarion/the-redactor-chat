# Architecture overview

The route-planning system has three parts: the planner web app, the routing engine and the tracking service.

The planner web app is where planners build daily routes. The routing engine computes routes overnight and on demand. The tracking service receives truck positions every 30 seconds and shows them on the planners' map.

All three run in our own Kubernetes cluster in an Amsterdam data centre. The routes database is PostgreSQL with a hot standby.
